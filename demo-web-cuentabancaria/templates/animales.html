Polimorfismo

menu_book Teoría: Sobrescritura de Métodos

El Polimorfismo permite que diferentes clases derivadas respondan a una misma instrucción o método común (hacer_sonido()), pero cada una ejecutando su propio comportamiento específico (Perro ladra, Gato maúlla).

# ==========================================
# EJERCICIO 4: POLIMORFISMO
# Diferentes clases responden al mismo método
# (hacer_sonido) con comportamientos únicos.
# ==========================================

# 1. Clase Base: Establece el contrato polimórfico
class Animal:
    def hacer_sonido(self) -> str:
        return "El animal hace un sonido genérico."


# 2. Subclase Perro: Sobrescribe el método base
class Perro(Animal):
    def hacer_sonido(self) -> str:
        return "El perro ladra: ¡Guau!"


# 3. Subclase Gato: Sobrescribe el método base
class Gato(Animal):
    def hacer_sonido(self) -> str:
        return "El gato maúlla: ¡Miau!"


# 4. Función Despachadora Polimórfica:
# Trata a cualquier subclase como Animal y ejecuta
# dinámicamente la versión correcta de hacer_sonido().
def emitir_sonido(animal: Animal) -> str:
    return animal.hacer_sonido()
